# KOTH 공개와 채점 작업

run_koth_cycle은 운영자가 승인한 문제 ID만 처리합니다
선택한 대회가 활성 상태이고 문제별 공개·마감 시각이 대회 범위 안에 있어야 합니다
문제 주소와 채점 주소·인증 설정이 준비되지 않은 문제는 공개하지 않습니다

공개 시각에는 SCHEDULED를 ACTIVE로, 마감 시각에는 CLOSED로 바꿉니다
운영자가 미리 CLOSED로 바꾼 문제를 다시 열지 않습니다
긴급 마감 시에는 closed_at도 실제 종료 구간 경계로 바꾸고 게이트웨이의 공개 허용도 해제합니다

점수는 종료된 15분 구간만 수집합니다
이전 작업이 실패했거나 서버가 재시작되면 아직 반영하지 못한 구간부터 따라잡습니다
한 번에 최대 6개 구간을 처리하고, 한 문제의 실패가 다른 문제의 조회를 막지 않게 순서를 나눕니다
이미 반영한 구간은 다시 지급하지 않습니다

같은 작업이 겹치면 PostgreSQL 세션 잠금으로 하나만 실행합니다
채점 서버 응답을 기다리는 동안 DB 트랜잭션을 열어 두지 않습니다
프로세스가 종료되면 세션 잠금도 풀립니다

배포 후 deploy/install_koth_cycle.py에 contest-id, 승인한 challenge-id 목록, event-date를 넘겨 설치합니다
설치 전 명령 존재 여부·마이그레이션·dry-run·systemd 구문을 확인합니다
해당 날짜의 한국 시각 09시부터 22시까지 매분 실행하며 다른 날에는 자동 실행하지 않습니다
VM 기동 예약과 외부 접속 게이트웨이 설정은 별도로 준비해야 합니다

검증 전인 문제는 승인 목록에 넣지 않습니다
대회 전 dry-run은 상태와 점수를 변경하지 않습니다
